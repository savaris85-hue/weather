Layers · Επιλογή γραφημάτων

Κάθε παράμετρος έχει δικό της χρώμα. Το ιστορικό φαίνεται πιο ανοιχτό και η πρόγνωση πιο σκούρα και έντονη.

Το γκρίζο υπόβαθρο δείχνει μέση τιμή και εύρος 10–90% για την ίδια εποχή — όχι μόνο πέρυσι.

Τα layers αναδιατάσσονται αυτόματα. Ορισμένα προγνωστικά δεδομένα μπορεί να μην είναι διαθέσιμα για κάθε μοντέλο ή ιστορική περίοδο. Τα κενά δεν αντικαθίστανται με επινοημένες τιμές.

Data: Open-Meteo · Radar: RainViewer (προαιρετικά, μόνο τελευταία 2ωρα) · Map: OpenStreetMap · Ανεξάρτητο open-source project, χωρίς σχέση με WeatherSpark ή WeatherDave. API free tier: μη εμπορική χρήση.
