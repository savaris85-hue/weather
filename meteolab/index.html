Νέος κανόνας ειδοποίησης

Επιστημονικές επιλογές (προαιρετικά)

Οι πιθανότητες βροχής προέρχονται από μοντέλο και δεν αποτελούν βαθμονομημένη αξιοπιστία ειδοποίησης. Η ωριαία πρόγνωση δεν επιτρέπει ασφαλή πρόβλεψη άφιξης σε 10 λεπτά.

Οι έλεγχοι γίνονται μόνο όσο η σελίδα είναι ανοιχτή. Για geofences χρησιμοποιείται η πρόγνωση στο κέντρο του πολυγώνου (όχι πλήρης κάλυψη περιοχής).

Πηγές πρόγνωσης

Επιλογή ανεξάρτητων μετεωρολογικών μοντέλων μέσω του δωρεάν Open-Meteo API. Δεν έχουν όλα τα μοντέλα πλήρες ορίζοντα 14 ημερών.

Το GFS καλύπτει έως 16 ημέρες. Ορισμένα άλλα μοντέλα έχουν μικρότερο ορίζοντα. Η απουσία δεδομένων εμφανίζεται ως —.

Κανάλια ειδοποιήσεων

In-app alerts

Ενεργό, όσο είναι ανοιχτή η εφαρμογή.

ON
Browser notification

Προαιρετικό, απαιτεί άδεια browser. Δεν λειτουργεί όταν η σελίδα είναι κλειστή.

Telegram Bot

Σχεδιασμένο ως μελλοντικός adapter. Απαιτεί ασφαλές server-side endpoint. Μην εισάγεις bot token στον browser.

Προγραμματισμένο
Google Sign-In

Προαιρετική μελλοντική σύνδεση, απαιτεί OAuth project και ασφαλή υποδομή.

Μονάδες μέτρησης

Θερμοκρασία σε °C · Άνεμος σε μποφόρ.

Οι μονάδες προβολής δεν αλλάζουν τα όρια των κανόνων.

Δεδομένα και αντίγραφα

Τα geofences, οι κανόνες και το ιστορικό αποθηκεύονται μόνο σε αυτόν τον browser. Αν αλλάξεις συσκευή, χρησιμοποίησε Export/Import.

Σημαντικές διευκρινίσεις

Η πρώτη έκδοση είναι δωρεάν static web app. Χωρίς backend δεν μπορεί να υποστηρίξει ασφαλές Google login, Telegram bot, 24/7 ειδοποιήσεις ή πραγματικό AI API χωρίς κλειδιά. Οι προγνώσεις δεν είναι εγγυήσεις.
